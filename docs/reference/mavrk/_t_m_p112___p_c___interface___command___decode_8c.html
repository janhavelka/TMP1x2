Detailed Description

Setup the interface from the MAVRK board to the PC Application for TMP112 TMP Sensors.

Author:
Mike Claassen
Date:
May 2010

The TMP112_PC_Interface_Command_Decode functions process and replies to command packets from the PC Application for the TMP112 devices.

Note:
Prototypes for functions in this file are located in the TMP112_Temp_Sensor.h header file located in the mavrk_embedded\Modular_EVM_Libraries\Components\TMP_Sensor_Template directory
See also:
For Support: http://ti.com/mavrkquestions

unsigned char mvk_Return_TMP112_Current_Configuration ( unsigned char  device_slot,
unsigned int  I2C_slave_address,
char *  request_list,
char *  output_data 
)

Processes the request list from the PC Interface for current state information.

The PC Interface will send a command requesting the current state information. The request will contain a list of Function Requests. This function will return a list containing the Function Request and the current value of the system for that specific request. For example, a request of the TMP112_READ_TEMPERATURE will return the current temperature of the device. The list of Function Requests will be terminated with a 0.

Parameters:
[in]device_slotTarget component slot on MAVRK board
[in]I2C_slave_addressTMP112 I2C slave address
[in]request_listPointer to a list of Function Requests from the PC Interface
[out]output_dataPointer to the location to place the resultant list of Function Requests and Data
Returns:
Number of Function Requests processed.
