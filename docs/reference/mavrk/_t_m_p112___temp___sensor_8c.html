Detailed Description

Perform interactions with the TMP112 via the I2C bus.

Author:
Mike Claassen
Date:
April 2010

The TMP112_Temp_Sensor functions initialize and configure the various settings in the TMP112 Temp Sensor devices.

Note:
Prototypes for functions in this file are located in the TMP112_Temp_Sensor.h header file located in the mavrk_embedded\Modular_EVM_Libraries\Components\TMP_Sensor_Template directory
See also:
For Support: http://ti.com/mavrkquestions

unsigned char  device_slot,
unsigned int  I2C_device_address 
)

Set the TMP112 Temp Sensor Thermostat mode.

This function writes the registers used to set the thermostat mode on the TMP112 Temperateure Sensors. The TMP112_INTERRUPT_CLEARED_BY_TEMPERATURE mode will allow the interrupt to clear if the temperature no longer exceeds the threshold. The TMP112_INTERRUPT_CLEARED_BY_READ mode will latch the interrupt until cleared by the software via a read.

Parameters:
[in]modeMethod used to clear alerts (TMP112_INTERRUPT_CLEARED_BY_READ or TMP112_INTERRUPT_CLEARED_BY_TEMPERATURE)
[in]device_slotDefines slot where TMP112 device is located on the MB-PRO-MVK motherboard
