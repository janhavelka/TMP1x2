unsigned char mvk_Create_TMP112_Constant_Table ( unsigned char  device_slot,
unsigned int  I2C_device_address,
unsigned int *  constant_table_pointer 
)

Capture the current register settings into a Constants Table format.

The function will capture the current values of the TMP112 configurable registers and load them into a constant table. This information may be used by developers to modify the default Constant Table or develop additional constant tables for various operational modes/configurations.

Parameters:
[in]device_slotMAVRK slot occupied by the given device (MAVRK_RFx, MAVRK_AFEx, MAVRK_SCIx)
[in]I2C_device_addressTMP112 I2C slave address
[out]constant_table_pointerPointer to the table to place the address and register pairs for the TMP112. Size of the table must be at least TMP112_DEFAULT_CONSTANT_TABLE_SIZE bytes
Returns:
Number of bytes in the constant table
Note:
This function will return the current settings of the configurable registers. It will order the table in a logical method to be used by a future block of software looking to provide a new constant table for the mvk_Init_TMP112_Via_Constant_Table() function. The mvk_Init_TMP112_Via_Constant_Table() function can load registers multiple times with different settings to provide a rudimentary scripting type functionality. This function will only return each configurable register one time in the table.
Warning:
This function will write TMP112_DEFAULT_CONSTANT_TABLE_SIZE bytes worth of information to the constant_table_pointer address. If the memory allocated is not large enough, and overwrite will occur. It is the developers responsibility to assure the table is large enough!

Initialize the TMP112 using a Constants Table of known good settings.

The function will load the TMP112 with a set of values from a table. This function allows a user to load a known register setttings or to save a set of registers and reload them at a future time.

Parameters:
[in]device_slotMAVRK slot occupied by the given device (MAVRK_RFx, MAVRK_AFEx, MAVRK_SCIx)
[in]I2C_device_addressTMP112 I2C slave address
[in]install_table_pointerPointer to the table of address and register pairs to load into the TMP112
[in]install_table_lengthNumber of total bytes in install_table_pointer
Returns:
None
Note:
This function can be used to load any subset of registers for the device. The input table expects sets of register address / value pairs that get loaded into the device one register at a time in the specified order. The default TMP112_Default_Register_Settings table in this file performs a standard initialization, but other settings may be developed to perform other tasks.
As this function loads addresses and values for any number of registers, a simple script can be developed to perform some functions. As an poor example, an lock bit could be cleared in a register, a number of configurations performed, and then the lock bit set in the original register.

Set the TMP112 Temp Sensor Thermostat mode.

This function writes the registers used to set the thermostat mode on the TMP112 Temperateure Sensors. The TMP112_INTERRUPT_CLEARED_BY_TEMPERATURE mode will allow the interrupt to clear if the temperature no longer exceeds the threshold.
